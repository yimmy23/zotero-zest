## 1. 推荐布局与 Z 按钮

1. 打开 Zotero 文库，在条目列表上方找到 **Z** 按钮。
2. 选择 **套用 Zest 推荐列布局**。它会排列标题、简记、年份、作者、阅读、状态、评级、出版物、期刊标签、影响因子、被引数、添加日期与附件，并按添加日期倒序。
3. 右键列标题，可决定显示哪些列；拖动列标题或边界可以调整顺序与宽度。
4. 要恢复切换前的布局，右键列标题，进入 **Zest 视图 → 恢复切换前的列布局**。

第一次套用推荐布局会开启它需要的 Zest 列。之后再套用时会保留你在设置中关闭的列；
如某列仍未出现，先到 **Zest 设置… → 条目列表列** 或该功能对应分组检查开关，再检查列标题菜单。

Z 按钮提供以下常用入口：

| 菜单项                              | 用途                                 |
| ----------------------------------- | ------------------------------------ |
| 文库关系图                          | 展开或收起条目列表下方的关系图       |
| 阅读统计…                           | 打开独立的统计窗口                   |
| 标注矩阵…                           | 集中回顾一组文献的标注               |
| 套用 Zest 推荐列布局                | 应用推荐的列顺序                     |
| 联网获取期刊数据（分区 / 影响因子） | 切换期刊数据自动查询，默认关闭       |
| 嵌套标签树                          | 在嵌套标签树与原生标签选择器之间切换 |
| Zest 设置…                          | 打开功能、外观与数据设置             |

选中一篇文献后，右侧 **Zest** 面板集中显示文献信息和阅读操作。
阅读器右侧的上下文面板也有相同入口；另有阅读统计、标注矩阵和文库关系图侧栏工具。
空选或多选时，Zotero 可能不显示这些条目区域，可从 Z 菜单打开独立工具。

## 2. 阅读记录、状态与评级

### 记录阅读过程

1. 在 Zotero 内置阅读器中打开 PDF 或 EPUB，保持阅读器处于前台。
2. 阅读时长会累计到 **阅读** 列及右侧 Zest 面板；热力条显示每页停留情况。
3. 在 Zest 面板点击热力条中的一段，可以跳转到相应页面。
4. 从 **Z → 阅读统计…** 查看每日目标、趋势、年度热力图和阅读排行。

计时默认开启。无键鼠输入超过 **120 秒**时暂停，朗读正在播放时可继续计时。
可在设置的 **阅读记录** 分组调整停表时间。
统计默认目标为每天 **30 分钟**、每周 **5 天**，可在统计界面的目标控件中修改。
阅读时长反映本机记录的停留时间，不等同于阅读理解程度。

### 自动显示与写入状态

条目尚未保存状态时，Zest 默认按阅读记录及 Zotero 的最近阅读信息显示 **未读 / 在读 / 已读**。
默认“已读”阈值为看过 **90% 的页数**且累计阅读至少 **5 分钟**，可在设置中调整。
自动判定使用空心圈；已经存入条目的状态使用实心点。

手动设置有三个入口：点击状态列圆点、右键条目 **Zest → 阅读状态**，或点击右侧面板的状态按钮。
“清除状态”移除已保存状态后，可重新显示自动判定结果。

设置中的两个选项作用不同：

- **未设置状态时自动判定**：只计算显示结果，不写入条目字段。
- **同时写入 Extra**：默认开启，可随阅读把已有的“未读 / 待读”推进为“在读”，跨过阈值后更新为“已读”。
  **对还没有状态的条目也生效**默认关闭；保持关闭时，无状态条目仍只显示自动判定。

如希望状态完全由自己维护，关闭“同时写入 Extra”。已经存入 `Extra` 的状态可随 Zotero 同步，
原始阅读时长则需要[单独导出](#data)。

### 星级与简记

- 点击第几颗星即可设置相应星级；再次点击当前最高星可降一级，一星可降到零。
- 右键条目 **Zest → 评级** 也可操作，支持对所选文献批量设置。
- 已有纯星级标签时，可在评级菜单中选择 **从星级标签导入评级…**，先检查预览再确认；已有评级、冲突标签和只读条目会跳过，原标签保留。
- **简记**是一行备注：双击简记列，或在 Zest 面板编辑。若保存失败，按提示重试。

评级与简记保存在条目的 `Extra` 中。只读文库可以查看，但不能保存这些修改。

## 3. 期刊分区、影响因子与被引数

### 先配置来源，再选择查询方式

打开 **Zest 设置… → 期刊分级**。数据按以下优先级取用：

| 来源           | 配置                                                        | 能提供什么                                        |
| -------------- | ----------------------------------------------------------- | ------------------------------------------------- |
| 本地期刊数据集 | 在“本地期刊数据集”中导入 CSV / JSON                         | 你自己的机构列表或分区表，优先于在线来源          |
| easyScholar    | 勾选来源，填写 easyScholar 密钥，点击“保存”；可用“检查”测试 | 来源收录的分区、分级与影响因子字段                |
| OpenAlex       | 勾选来源，当前适配器无需填写密钥                            | 两年平均被引率等 OpenAlex 指标；不是 JCR 影响因子 |

期刊自动查询默认关闭。完成配置后可以：

1. **只查询当前所选文献**：选中文献，右键 **Zest → 刷新所选条目的期刊数据**。
2. **随列表浏览自动查询**：打开 **Z → 联网获取期刊数据（分区 / 影响因子）**；这对应设置中的 **显示条目时自动抓取**。
3. 需要停止自动查询时，取消相同选项。已有缓存仍可显示。

手动刷新使用已启用的来源，不要求开启自动查询。本地数据集不需要网络；
只使用本地数据时，可关闭 easyScholar 和 OpenAlex，再手动刷新所选文献。

### 新锐优先，中科院历史分区备选

默认字段为 `xr, sci, sciif`：

- 中文界面按 **新锐 → JCR 分区 → 影响因子**排列。
- 新锐没有有效数据时，同一分区位置使用 **中科院历史分区**作为备选，并明确区分体系名称。
- 英文界面默认按 **JCR → XR（或 CAS）→ IF**排列。
- 自定义的字段顺序优先。如需同时查看两套分区，可在“字段”中填写 `xr, sciUp, sciif`。

新锐与中科院是不同体系，备选显示不表示二者等价。没有来源年份时，查询日期不会被当作分区年份。
悬停徽章可查看字段、来源与完整名称。没有上述分区数据时，界面可回退显示 OpenAlex 指标；
`oa2yr` 是两年平均被引率，不应作为 JCR IF 使用。**影响因子**列也可能回退显示这一数值，
请悬停查看实际字段与来源，不能仅凭列名判断它是 JCR IF。

### 导入本地期刊表

1. 准备 CSV 或 JSON 文件，至少包含 `name` 或 `issn` 之一；其余列作为指标字段。
2. 打开设置中的 **本地期刊数据集 → 导入数据集…**，选择文件。
3. 在“期刊分级”的“字段”中填入要显示的字段名称，再刷新所选条目。

CSV 示例中的刊名、标识符和数值仅演示格式：

```csv
name,issn,eissn,xr,sciUp,sci,sciif
Example Journal,1234-5678,8765-4321,医学1区,医学2区,Q1,5.2
```

导入会收集 ISSN、pISSN、eISSN 等标识列。印刷版与电子版标识需要数据行自身或经核实的来源关联；
同名但标识矛盾的数据不会仅凭相似刊名合并。使用你有权访问且适用于自己研究要求的数据表。

### 期刊数据没出现时

依次检查：列是否启用、字段名称、来源开关、easyScholar 密钥，以及条目的刊名、ISSN、DOI。
例如 `Cancer Immunology, Immunotherapy : CII` 已有明确别名映射，可直接查询；无需改写原始题名。
真实副标题及有区分意义的括号内容会保留，其他缩写不保证能自动识别。

期刊结果默认缓存 **30 天**。更新来源配置或修正文献元数据后，可先手动刷新；
来源限流时应稍后重试，反复点击刷新不会绕过退避。设置中的 **清空分级缓存**可用于重新查询，
但不会补出来源本身没有的数据。

### 更新被引数

选中文献后，右键 **Zest → 更新被引数**。默认依次使用 Crossref、OpenAlex；
Semantic Scholar 可在设置中另行启用。条目需要 DOI 或 PMID。

被引数及来源日期写入 `Extra`，查询由你手动发起；已有的其他插件字段会保留。
不同平台的被引数统计范围不同，比较时请同时查看来源和更新时间。

## 4. 引用键 Citation Key

引用键是写作工具用于定位文献的短标识，例如 `Wang2025NSCLC`。
选中文献，在右侧 **Zest → 引用键**查看，点击 **复制引用键**，或选中文字手动复制。

Zest 依次读取：

1. Zotero 原生 `citationKey` 字段。
2. 旧资料在 `Extra` 中已有的 `Citation Key:` 行，例如：

   ```text
   Citation Key: Wang2025NSCLC
   ```

3. Better BibTeX 已有的引用键缓存。

Zest 只读取，不生成、重命名或固定引用键，也不会把内部条目 key 当作引用键。
没有可读值时，该栏显示 **尚无引用键**，复制按钮不可用。先在 Zotero 或 Better BibTeX 中设置引用键，
再重新选中条目查看；未安装 Better BibTeX 也可以显示前两种已有值。
只读文库中已有的引用键仍可复制。

## 5. 条目信息与摘要

在设置 **条目面板** 分组中确认 **显示 Zest 面板**与**显示摘要**已开启。
面板把标题、引用键、期刊、作者机构、摘要和阅读操作放在一起。

### 查看和补全摘要

1. 选中文献，展开 Zest 面板的摘要；较长时点击 **阅读完整摘要**。
2. 摘要缺失时点击 **获取摘要**，已有文字不完整时可用 **查找完整摘要**。
3. Zest 按 DOI / PMID 查询 Europe PMC、PubMed，以及满足身份校验条件的 Crossref 结果。
4. 有来源链接时可点击 **查看来源**核对。

补全结果用于面板展示，不覆盖条目原有的摘要字段。无可靠标识符、来源无摘要或暂时不可达时，
可能无法获取完整内容；请先检查条目 DOI / PMID。

### 翻译摘要

点击 **翻译**才会请求中文译文，点击 **原文**返回原文；译文与原文共用一个摘要区域。
优先使用 Translate for Zotero 已配置的默认翻译引擎，未安装该插件时使用内置 Microsoft 网页翻译服务。
已配置引擎失败时不会自动切换到另一服务。

Zest 没有独立的翻译引擎选择项；使用 Translate for Zotero 时，请在该插件中调整引擎。
翻译需要发送摘要文本，服务可用性取决于所选来源。译文只用于展示，不写回摘要或 `Extra`。

### 作者与机构

作者列表可展开，优先展示明确标记的一作和通讯作者；缺少一作标记时按作者列表首位展示。
缺少通讯标记时显示“末位”，表示作者列表最后一位，不代表已经确认通讯作者。

机构优先使用本地缓存，缺少信息时点击 **获取机构信息**或**补全作者信息**，
将当前条目的 DOI 发送到 OpenAlex。设置中的 **浏览条目时自动获取作者机构**默认关闭，
按需开启后才会在可见面板中停留时自动查询。

## 6. 标注矩阵与标注定位

### 集中回顾一组文献

1. 先在 Zotero 中打开需要的分类、搜索结果，或选中一组文献 / 附件。
2. 点击 **Z → 标注矩阵…**。
3. 在 **文献范围**中选择 **当前视图**或**已选文献 / 附件**。
4. 按文献、标注类型、颜色、标签或“仅有批注”筛选，也可输入关键词。
5. 点击 **定位原文**返回标注所在位置；列表中的分页用于浏览结果。

搜索支持空格连接关键词、`|` 表示任一词、`-词`排除，以及双引号包围的完整短语。
需要重新读取文库内容时点击 **刷新**。

通过 **导出**菜单选择 CSV、Markdown 或 **复制为 Markdown**。
复制和导出包含筛选后的全部结果，不限于当前页；Markdown 可粘贴到 Obsidian 等编辑器，
并保留 Zotero 原文定位链接。图片类标注保留来源链接，不会把图片文件一并复制过去。

右侧 **Zest · 标注矩阵**默认查看当前文献；在文库中可切换至当前视图，
阅读器侧栏则围绕当前文献使用。

### 单篇标注定位

文库右侧 **标注定位**列出当前文献的标注，并响应标签树中选中的标签。
卡片上可复制文本或定位原文；正文允许选取，双击页码也可跳转。
如没有结果，检查附件是否存在、是否已有 Zotero 标注，以及当前标签筛选是否过窄。

## 7. 标签树与列视图

### 使用嵌套标签

1. 给文献设置类似 `#方法/统计/生存分析` 的标签，默认分隔符是 `/`。
2. 从 **Z → 嵌套标签树**打开，或在设置的 **嵌套标签树**分组开启。
3. 点击父分支，按其下面的标签筛选文献；可通过搜索和排序找到分支。
4. 右键分支可重命名、设置颜色或 Emoji。整枝重命名涉及合并时，先核对确认提示。
5. 要回到 Zotero 原生标签选择器，切到 **全部**，或关闭嵌套标签树。

键盘支持上下移动、左右折叠 / 展开、Enter / 空格选中，以及 Esc 清空标签搜索。
默认还会匹配附件、笔记与批注上的标签，可在设置中调整。

**#标签**列与标签树共用匹配规则。默认 `#` 匹配以 `#` 开头的标签；
`~~X` 排除以 X 开头的标签，`/正则/`可用于更具体的匹配。
独立的**标签**列用于彩色与 Emoji 标签，默认关闭。

### 保存列视图

1. 先调整列的显示、顺序、宽度与排序。
2. 右键列标题，选择 **Zest 视图 → 把当前列布局保存为视图…**，命名为“筛选”或“写作”等。
3. 以后从相同菜单切换、更新或删除视图。
4. `Alt+,` / `Alt+.` 可前后切换视图；**恢复切换前的列布局**用于恢复上一次布局。

作者列的姓名顺序、显示人数和“我的名字”高亮，可在设置的 **作者列**中调整。
这些显示规则不会改写 Zotero 原始作者字段。

## 8. 文库关系图与作者身份

1. 打开需要分析的文库视图，点击 **Z → 文库关系图**。
2. 在 **条目关联 / 作者 / 标签 / 分类**中选择关联方式。
3. 在 **筛选与操作**中调整作者范围或共享条目阈值；范围变化后可点击 **重新分析**。
4. 点击 **适配视图**查看完整图谱；拖动节点或空白处，使用 Ctrl / ⌘ + 滚轮缩放。
5. 右键节点可在文库中显示或打开对应文献。

作者模式默认展示 **首位+末位**，可改为 **全部作者**；这里的位次不代表通讯作者身份。
默认共享阈值为 **2 篇**，图谱最多显示 **250 个节点**；大型范围会保留连接较多的部分。
没有连线时，可降低共享阈值或扩大当前文献范围。

恢复图谱、切换范围及重新分析均使用本地文献与已有缓存。
需要补充在线作者身份时，在作者模式点击 **补全作者身份**，从 OpenAlex 获取当前范围的缺失信息，
每次最多请求 **30 篇**。切换范围或关闭图谱会停止后续请求。

图谱用于整理已经收藏的文献关系，不提供库外文献的引文发现。右侧 **Zest · 文库关系图**
还可查看当前文献及其本地关联；需要更大空间时，在文库下方展开。

<a id="tabs"></a>

## 9. 垂直标签页

1. 选择 **工具 → Zest → 垂直标签页**，或在设置的同名分组开启侧栏。
2. 使用 **筛选标签页**查找已打开文档。固定的 **文库**入口始终保留，可返回条目列表。
3. 右键文档可关闭、在文库中显示，或通过 **移入分组 → 新建分组…**整理文档；也可拖动调整。
4. 从 **会话与选项 → 保存当前标签页集合…**保存当前文档集合，之后用 **重新打开已保存的集合**恢复。
5. 需要隐藏顶部标签栏时，启用 **隐藏 Zotero 自带的标签栏**；关闭侧栏后可恢复原生标签栏。

上下方向键及 Home / End 在可见入口间移动；Enter / 空格激活文档或折叠分组，左右方向键展开 / 折叠分组。
关闭按钮与文档激活按钮分开，可通过 Tab 到达当前行的关闭操作。

垂直侧栏默认关闭，分组与保存的集合保存在 Zest 配置中。保存集合不复制 PDF；
重新打开时仍需要当前文库中的对应附件可用。

<a id="data"></a>

## 10. 数据导出、导入与备份

### 先区分要转移的数据

| 数据                                           | 保存位置 / 转移方式                                        |
| ---------------------------------------------- | ---------------------------------------------------------- |
| 阅读时长、每页与每日记录                       | Zotero 数据目录的 `zest.sqlite`；使用阅读记录导出 / 导入   |
| 已写入的阅读状态、评级、简记、被引数           | 条目 `Extra`；随 Zotero 条目同步                           |
| 视图、标签规则、标签页分组与集合、数据集元数据 | `zest-config.json`；使用配置导出 / 导入                    |
| 本地期刊数据集内容                             | `zest-datasets` 文件夹；在新环境重新导入原始 CSV / JSON    |
| 查询缓存                                       | `zest-cache.json`；可重新获取，不替代原始数据备份          |
| API 密钥                                       | 优先保存在登录管理器；不包含在配置导出中，需要单独重新配置 |

### 转移阅读记录

1. 在来源电脑选择 **工具 → Zest → 导出阅读记录（JSON）…**或**导出阅读记录（CSV）…**。
   设置中的 **阅读数据**分组也提供这些入口。
2. 在目标电脑先同步相同账号 / 群组中的 Zotero 条目与所需附件。
3. 选择 **工具 → Zest → 导入阅读记录（JSON / CSV）…**，打开导出的文件。
4. 选择 **合并（取较大值）**或**累加**，完成后检查已导入和跳过数量。

重复备份或存在重叠记录时，通常选择“合并（取较大值）”以免重复累计。
“累加”仅适用于确认互不重叠、明细覆盖一致的记录；明细无法安全相加时会给出提示。

新版导出使用账号 / 群组身份与条目 key 匹配，不依赖两台电脑上相同的本地文库编号。
未登录账号的本地文库备份仅能按原配置文件身份匹配；旧文件缺少身份信息时，要求条目 key 在当前文库中唯一。
缺失或歧义条目会跳过并报告。

### 转移配置与期刊表

在 **Zest 设置… → 配置**中使用 **导出配置… / 导入配置…**。
配置包不包含阅读记录、实际期刊数据集文件、文献附件或 API 密钥。
换电脑时，请分别导入阅读记录、重新导入期刊表，并重新配置需要的密钥。

设置若提示密钥改用了备用存储，请按界面提示处理；不要将密钥贴进问题报告。
删除阅读记录前先导出备份；“清除所选条目的阅读记录”会删除本地页级与每日时长，不能撤销。

## 11. 常见问题

**装好后看不到某个功能？**

先确认运行的是 Zotero 10，并已按安装提示重启。列表列可先套用推荐布局，再检查设置与列标题菜单。
侧栏功能需要选中文献或打开阅读器；空选 / 多选时可改用 Z 菜单中的独立窗口。

**为什么有 OpenAlex 数据，却没有新锐、中科院分区或 IF？**

OpenAlex 提供自己的被引指标，不提供这些分区或 JCR IF。检查 easyScholar 密钥、来源字段覆盖，
或导入有相应字段的本地期刊表。随后手动刷新所选条目。影响因子列中的数字也可能来自 `oa2yr` 回退，
请悬停核对实际字段与来源。

**为什么引用键显示“尚无引用键”？**

条目没有原生字段、兼容的 Extra 行或可读的 Better BibTeX 缓存。先在相应工具中设置引用键，
再重新选中条目。Zest 不会为了填满这一栏而自动生成 key。

**阅读时长为什么没有增加，或另一台电脑看不到？**

检查阅读记录开关、阅读器是否在前台、是否超过空闲停表时间。时长只在本机数据库记录，
不会随 Zotero 自动同步；跨设备使用阅读记录导出 / 导入。

**摘要、机构或作者身份一直没有结果？**

检查 DOI / PMID 是否正确，以及来源是否可用；机构和作者身份补全依赖 OpenAlex。
遇到限流提示时稍后重试。恢复图谱本身不会触发联网补全。

**如何恢复原生界面？**

关闭嵌套标签树或垂直标签页侧栏；关闭不需要的 Zest 列与标题装饰。
列布局可以从 **Zest 视图 → 恢复切换前的列布局**恢复上次切换前状态，或手动调整。

**如何给模板或脚本读取 Zest 数据？**

使用只读的 `Zotero.Zest.api`，接口定义和示例入口见 [src/api.ts](../src/api.ts)。
更多问题请提交 [Issue](https://github.com/yimmy23/zotero-zest/issues)，附版本、复现步骤与必要截图，移除密钥和私人内容。
